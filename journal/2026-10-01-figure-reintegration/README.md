# Figure reintegration

This journal prepares the next implementation pass: inventory the
historical figure resources that are still available and restore
usable figures to the reconstructed LaTeX document.

- [`AUTHOR.md`](AUTHOR.md) records the author's intent.
- [`PROMPT.md`](PROMPT.md) contains the operational directive for
  Codex.
- [`DONE.md`](DONE.md) records the implementation passes.
- `REVIEW.md` will be written independently after the work is
  complete.

The existing Phase 1 resource inventory under
[`new/latex/RESSOURCES.md`](../../new/latex/RESSOURCES.md) is an input
to this task, not a substitute for a fresh inventory of the historical
resource tree.
