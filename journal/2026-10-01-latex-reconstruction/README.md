# LaTeX reconstruction

Date: 2026-10-01

This journal records the Phase 1 reconstruction of the 1994 DEA LaTeX
project.

- `AUTHOR.md` records the reconstructed human intent.
- `PROMPT.md` records the detailed operational directive given to Codex.
- `DONE.md` records what Codex produced and points to the detailed
  documentation under `new/latex/`.
- `REVIEW.md` records the independent review of the completed work.

The records in this directory were reconstructed retrospectively after the
Phase 1 implementation. Each file says so where that distinction matters.
